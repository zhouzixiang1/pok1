# 风格对手池分析

## 对手池
- `bot002` / `tight_value`：紧凶价值型，只用较强牌主动加注，边缘牌偏保守。
- `bot003` / `loose_aggressive`：松凶压迫型，宽范围持续施压、加注频率高。
- `bot004` / `calling_station`：跟注站型，跟注范围宽，非强牌很少主动再加注。
- `bot005` / `probe_bluffer`：小探测偷池型，喜欢在干燥且对手过牌的牌面小额下注。
- `bot006` / `pressure_jammer`：压力全下型，落后或比赛后段更容易用 all-in 施压。

## 结果概览
| 对手 | 风格 | 当前 bot 胜-负-平 | 平均镜像筹码差 |
| --- | --- | ---: | ---: |
| bot002 | 紧凶价值 | 4-0-0 | 1178.0 |
| bot003 | 松凶压迫 | 4-0-0 | 13799.5 |
| bot004 | 跟注站 | 4-0-0 | 9172.0 |
| bot005 | 小探测偷池 | 4-0-0 | 13347.8 |
| bot006 | 压力全下 | 4-0-0 | 1136.0 |

当前 `1.py` 在两个座位方向上都击败了五种风格。最接近的是 `bot002` 和 `bot006`，它们更适合作为后续第一层压力测试；`bot003`、`bot004`、`bot005` 输得很大，适合做烟测对手，但不足以单独支撑修改主策略。

## 日志信号
- 没有发现非法输出或崩溃。
- `probe_raise` 出现频繁，尤其集中在 `bot002`、`bot004`、`bot006` 对局里。
- 面对 `bot004` 时，高损失样例多出现在低胜率连续探测/价值压力下注被跟到底的牌局。
- 面对 `bot006` 时，高损失样例多来自承压后的 check/call 或弃牌线，但整体收益仍为正。
- 面对 `bot002` 有一手大额亏损来自 anti-lock 压力/all-in，这应当按反锁定例外复盘，不应误判为普通策略漂移。

## 修改点讨论
- 不建议基于这一轮削弱当前主策略，因为当前 bot 对五个对手全部获胜。
- 后续候选策略优先用 `bot002` 和 `bot006` 做阻力测试，因为它们给出的平均筹码差最小。
- 如果要针对“跟注很宽”的对手做候选补丁，可以小范围实验：在 `fold_to_raise` 证据不足、胜率很低时，减少连续小探测下注，更多转向 check/控池。
- 如果要针对“压力全下”对手做候选补丁，可以复盘 `call_defense` 和河牌控池线是否错过价值，但需要更强对手或更多局数再改 `1.py`。
- 当前五个生成 bot 是起步对手池；下一轮 HL 更值得做的是生成一个专门针对当前 `1.py` 漏洞的更强对抗 bot。
