# Task Context: River Jam Restraint (v101 → v102)

## Problem Evidence

1. **Action stats** (n=1473 river decisions): `raise=23.5%, fold=9.4%, call=5.4%`
   - 23.5% river raise rate is catastrophically high

2. **Replay spotlight** (top swing hands):
   - G3H17: bot=[Ad Th] **allin with ONE PAIR** (A pair, T kicker) on AK4A7 → lost -20000
   - G2H3: bot=[Ks Kc] **allin with ONE PAIR** facing raise → won +20000 (got lucky)
   - G4H41: bot=[Qs Ks] called with one_pair (no pair on board) → lost -20000

3. **Battle experience** (190+ matchups):
   - "River allin≥18% reliably produces ≥7 big-loss games regardless of fold-gap"
   - "Cap river allin≤7% as PRIMARY target"
   - Sub-7% seats held losses to 1-2 games even when losing

4. **H2H weaknesses**: v97(0.40), v96(0.40), v100(0.40)

## Root Cause Analysis

### Facing all-in (strategy.py lines 818-852):
`jam_buffer` accumulates: 0.02 base + thin tier +0.04 + nutted_risk + line_strength + check_resistance
Capped at 0.14. For thin/marginal one-pair hands, this allows calling all-ins with ~0.35-0.45 equity.

### River raise sizing (choose_raise):
round_idx==3 base ratio = 0.85. With win_rate scaling (×1.50), hands with wr=0.65 get ratio=1.0 (pot-sized).
This produces huge raises that effectively commit the stack.

## Solution: Two-Part Fix

### Part 1: `_river_jam_restraint()` in strategy_helpers.py
New function that returns True when river all-in should be BLOCKED.

```python
def _river_jam_restraint(round_idx, value_profile, made_strength, draw_strength,
                          nutted_risk, anti_lock_pressure):
    """Block river all-in with marginal hands. Prevents 20000-chip commits with one pair."""
    if round_idx != 3:
        return False
    if anti_lock_pressure:
        return False
    if value_profile is not None and value_profile.get('tier') in ('strong', 'nut'):
        return False
    if made_strength >= 0.55:  # ~two-pair or better
        return False
    if draw_strength >= 0.14:
        return False
    if nutted_risk is not None and nutted_risk.get('risk', 0) >= 0.10:
        return False
    return True
```

### Part 2: Wire into strategy.py

**Facing all-in path (before line 852):**
```python
if _river_jam_restraint(round_idx, value_profile, made_strength, draw_strength, nutted_risk, anti_lock_pressure):
    if not anti_lock_jam_continue:
        return -1
```

**Shove path (before line 881):**
```python

    if not anti_lock_shove_continue:

```

### Part 3: River raise cap in choose_raise
For non-strong river hands, cap ratio at 0.65 instead of 0.85.

**In choose_raise (after line 206, where ratio is set for round_idx==3):**
```python
if round_idx == 3 and value_profile is not None and value_profile.get('tier') not in ('strong', 'nut') and not semi_bluff:
    ratio = min(ratio, 0.65)
```
