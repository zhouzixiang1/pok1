# Task Context: Nut-Hand Value Extraction — Kill the Induce Cap

## THE LEAK (confirmed across 33+ H2H pairs)
avg_raise collapses to 0.4x pot on turn/river across ALL matchups. v111 H2H avg
0.560 but loses 0.30-0.40 to elite bots (v96/v102/v107/v108/v104/v90) by bleeding
chips in close games — underbetting nut hands. v111 fold discipline is GOOD; it
loses by extracting too little value when ahead.

## ROOT CAUSE (traced in current source)
Two mechanisms converge to cap nut-hand sizing at ~0.40x pot:

1. **`value_bet_plan()` in postflop.py line 479**: for tier=="nut" on static boards
   when `pot < 2600`, sets `plan["induce"] = True`. This flows into `choose_raise()`
   via `value_plan.get("induce", False)`.

2. **`induce_nut_value` in strategy.py line 1184**: independently sets
   `induce_mode=True` for nut hands vs aggressive opponents (postflop_aggr>=0.38
   OR aggression>=0.34 OR fold_to_raise<0.46) with small pots.

BOTH paths trigger `induce_cap = 0.29 + 0.05*round_idx + 0.05*wetness` in
`choose_raise()` lines 236-239:
```python
inducing_value = (induce_mode or value_plan.get("induce", False)) and to_call == 0 and value_profile.get("tier") == "nut"
if inducing_value:
    induce_cap = 0.29 + 0.05 * round_idx + 0.05 * wetness
    ratio = min(ratio, induce_cap)
```

### Numeric trace (nut hand, turn round_idx=2, pot=800, wetness=0.15, OOP):
- Intended ratio BEFORE cap: 1.18x pot (base 0.70 + win_rate 0.39 + size_bonus 0.232 - 0.12 - 0.07)
- induce_cap: 0.29 + 0.10 + 0.0075 = 0.398
- ACTUAL ratio after cap: 0.398x pot
- **VALUE LOST: 0.78x pot per nut-hand bet on the turn**
- River (round_idx=3): intended 1.39x → capped at 0.448x. VALUE LOST: 0.94x pot.

## WHY INDUCING IS WRONG HERE
Inducing (underbetting to keep opponent in) only works vs aggressive opponents
who will raise-into our small bet. But:
- vs passive/calling-station opponents: they just call our small bet → we LOSE value
- vs balanced elite opponents (v102/v107/v108): they fold to our bigger bets anyway,
  but when they DO call, we need to extract. Inducing at 0.40x extracts almost nothing.
- The induce cap (0.40x) is so low it leaves value on the table even when inducing
  "works" (opponent raises) — they can just call 0.40x cheaply.

## THE FIX (Logic Architect scope)
Modify `choose_raise()` in strategy.py: **raise the induce cap and gate it on
opponent evidence.** The cap should only apply when we have positive evidence the
opponent is aggressive (will bet into us), and even then the floor should be higher.

Current code (lines 236-239):
```python
inducing_value = (induce_mode or value_plan.get("induce", False)) and to_call == 0 and value_profile.get("tier") == "nut"
if inducing_value:
    induce_cap = 0.29 + 0.05 * round_idx + 0.05 * wetness
    ratio = min(ratio, induce_cap)
```

### Required changes:

**Change 1 — `value_bet_plan()` in postflop.py line 478-481**: Stop setting
`plan["induce"]=True` unconditionally for nut hands on static boards. Only induce
when the opponent is confirmed aggressive (this check happens in strategy.py
via `induce_nut_value`, so value_bet_plan should NOT set induce itself — the
`induce_nut_value` path already handles the opponent-aggression gate).

Replace:
```python
        else:
            plan["induce"] = pot < 2600
            plan["size_delta"] -= 0.12 if round_idx < 3 else 0.16
            plan["label"] = "nut_value_induce"
```
With:
```python
        else:
            # Do NOT unconditionally induce (underbet) nut hands on static boards.
            # The induce_nut_value path in strategy.py already gates on opponent
            # aggression evidence. Unconditional induce here crushed nut-hand
            # sizing to 0.40x pot across all matchups (confirmed 33+ H2H pairs).
            plan["size_delta"] += 0.02 + 0.03 * wetness
            plan["label"] = "nut_value_static"
```

**Change 2 — `choose_raise()` in strategy.py lines 236-239**: Raise the induce cap
floor from 0.29 to 0.55 and scale by round_idx more aggressively, so even when
inducing IS active (via induce_nut_value vs confirmed aggressive opponents), the
minimum nut-hand bet is 0.55x+ pot, not 0.40x.

Replace:
```python
    inducing_value = (induce_mode or value_plan.get("induce", False)) and to_call == 0 and value_profile.get("tier") == "nut"
    if inducing_value:
        induce_cap = 0.29 + 0.05 * round_idx + 0.05 * wetness
        ratio = min(ratio, induce_cap)
```
With:
```python
    inducing_value = induce_mode and to_call == 0 and value_profile.get("tier") == "nut"
    if inducing_value:
        # Induce only vs confirmed aggressive opponents (induce_mode gate in
        # strategy.py). Even then, nut hands must bet at least 0.55x pot —
        # the old 0.29+0.05*round_idx cap crushed value to 0.40x, confirmed
        # as the primary postflop value-extraction leak (33+ H2H pairs).
        induce_cap = 0.55 + 0.06 * round_idx + 0.04 * wetness
        ratio = min(ratio, induce_cap)
```

Note: `value_plan.get("induce")` is removed from the inducing_value condition
because Change 1 stops value_bet_plan from setting it. The induce_nut_value
path (strategy.py line 1184, passed as induce_mode=) already gates on opponent
aggression evidence (postflop_aggr>=0.38 etc.), which is the correct condition.
