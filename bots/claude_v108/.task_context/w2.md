### Logic
When facing a river bet (round_idx == 3, to_call > 0), check opponent's river bet-size tendency:

1. If tendency class == **"overbet_polar"** (confidence >= 0.20):
   - Opponent's river bets are polarized (nuts or air)
   - Fold medium-strength hands (made_strength < 0.45) that have no draw and aren't nut/strong tier
   - This is because vs a polarized range, medium hands lose to their value and beat their bluffs — but the sizing means we're getting bad implied odds
   - Ground in pot odds: only fold if `made_strength < pot_odds - 0.05` (equity meaningfully below call price)

2. If tendency class == **"underbet_trap"** (confidence >= 0.20):
   - Opponent bets small with strong hands (trapping)
   - TIGHTEN fold range — fold weak hands (made_strength < 0.30) even vs small bets
   - This is the inverse: their small bets are traps, not bluffs

3. If **"standard"**:
   - Return False (no fold gate fires)
