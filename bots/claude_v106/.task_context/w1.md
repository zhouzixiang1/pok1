## Root Cause

In strategy.py line 1392, `probe_mode` is set to True when:
```python
probe_mode=check_probe or small_probe or (value_profile and value_profile["tier"] == "thin" and board_texture and not board_texture["dynamic"])
```

The third condition fires for ALL thin value hands on static boards. This is incorrect:
- "thin" tier includes top-pair-good-kicker, middle pair, overpairs — real value hands
- When probe_mode=True, choose_raise caps ratio to 0.25+0.08*wetness (~0.25-0.33x pot)
- This gives draws profitable odds to call (pot odds ~25-30%)
