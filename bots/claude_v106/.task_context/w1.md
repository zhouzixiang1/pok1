# Wet-Board Value Barrel Worker Task

## GOAL
Add a `_wet_board_value_barrel()` function to strategy.py that provides enhanced
value-escalation sizing for strong/nut hands on WET boards (wetness > 0.30).

This is the wet-board complement to v105's `_dry_board_value_barrel()` which
covers dry boards (wetness ≤ 0.25). The gap: there is NO value-escalation path
for strong/nut hands on wet/connected/monotone textures where opponents are
drawing and the default `choose_raise` under-sizes at ~0.4-0.6x pot.

## KEY LOGIC (code skeleton)
```python
def _wet_board_value_barrel(value_profile, round_idx, board_texture, opponent_model,
    made_strength, draw_strength, my_cards, public_cards,
    to_call, pot, my_chips, min_raise, my_round_bet,
    sizing_exploit_delta, flush_profile, nutted_risk):
    # Guard: only postflop strong/nut on WET boards
    if round_idx == 0:
        return None
    if value_profile is None or value_profile.get("tier") not in ("strong", "nut"):
        return None
    if board_texture is None:
        return None
    wetness = board_texture.get("wetness", 0.0)
    if wetness <= 0.30:
        return None  # dry boards handled by _dry_board_value_barrel
    
    # Don't interfere with trap logic on flop
    if round_idx == 1 and _should_checkraise_trap(
        value_profile, round_idx, board_texture, opponent_model,
        my_cards, public_cards):
        return None
    
    # Don't fire when facing a bet (to_call > 0) — that's call/raise territory
    if to_call > 0:
        return None
    
    # Don't fire if nutted risk is high (board is dangerous to our hand)
    if nutted_risk is not None and nutted_risk.get("risk", 0.0) > 0.08:
        return None
    
    tier = value_profile.get("tier", "none")
    dynamic = board_texture.get("dynamic", False)
    paired = board_texture.get("paired", False)
    
    # Base ratio: larger on later streets and wetter boards
    if round_idx == 1:   # flop
        base_ratio = 0.68
    elif round_idx == 2: # turn
        base_ratio = 0.78
    else:                # river
        base_ratio = 0.85
    
    # Scale UP with wetness (more draw protection needed)
    base_ratio += 0.10 * (wetness - 0.30)  # +0.07 to +0.10 for very wet
    
    # Nut hands bet bigger
    if tier == "nut":
        base_ratio += 0.05
    
    # Dynamic boards (straight/flush draws present): size up to charge draws
    if dynamic:
        base_ratio += 0.05
    
    # Flush draw on board + we don't have the flush: protect by betting bigger
    if flush_profile is not None and not flush_profile.get("has_flush", False):
        if flush_profile.get("board_flush_possible", False):
            base_ratio += 0.04
    
    # Opponent exploitation: sticky opponents (low fold) get bigger sizing
    fold_to_raise = opponent_model.get("fold_to_raise", 0.45)
    if fold_to_raise < 0.42:
        base_ratio += 0.05
    elif fold_to_raise > 0.55:
        base_ratio -= 0.03
    
    base_ratio += sizing_exploit_delta
    
    base_ratio = clamp(base_ratio, 0.55, 1.05)
    
    pot_after_call = pot + to_call
    amount = int(to_call + pot_after_call * base_ratio)
    amount = max(min_raise, amount)
    amount = min(amount, my_chips - 1)
    
    if amount <= to_call or amount < min_raise or amount >= my_chips:
        return None
    return amount
```
