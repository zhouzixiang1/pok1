## The Problem

Match analysis shows avg_raise is frozen at 0.4x pot across all streets (flop/turn/river). The `_dry_board_value_barrel()` function was added in v106 to extract more value on truly DRY boards (wetness ≤ 0.25, not dynamic, not paired) — it bets 0.72-0.88x pot.

But on **moderate-dry boards** (wetness 0.26-0.45, still not dynamic, not paired), strong/nut hands fall through to `choose_raise()` which hits multiple suppressive caps:
- `induce_cap` = 0.29 (line 239) when inducing
- `thin_cap` = 0.30 (line 252) when thin_control
- `low_ratio` floor = 0.40 (line 254)
- probe_mode ratio = 0.25 (line 242)

Result: strong hands on moderate boards bet only 0.40x pot, leaving value on the table.

## The Fix

This is still significantly better than the 0.40x default from choose_raise.
