# Retired Agent Context

This directory preserves historical editor/agent specifications, memories,
permissions, and workflows from the mixed Botzone and `national_native_v1`
eras. It is `legacy-untrusted` archive material.

Active agents, prompts, tests, and evolution stages must not load, summarize,
execute, or use these files as planning evidence. Current instructions live
only in the root `AGENTS.md`, the active `CLAUDE.md` files, and current
documents outside `archive/`.
