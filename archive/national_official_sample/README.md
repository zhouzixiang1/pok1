# Archived Official Sample

This directory preserves the original competition sample client and its local
launcher for provenance only. The sample does not implement the repository's
current bounded raw-stream parser, typed policy ABI, process supervision, or
unsolicited-action protections.

Active diagnostics use `scripts/official_scripted_bot.py`; generated bots use
the system-owned national runtime. Nothing in the active pipeline imports or
launches files in this directory.
