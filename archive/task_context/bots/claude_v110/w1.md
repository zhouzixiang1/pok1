# Worker 1 Task Context: Value Sizing Floor + Turn Check-Raise

## The Leak (CONFIRMED)
Postflop avg_raise is stuck at **0.4x pot** on flop/turn and 0.5x on river across ALL matches (battle experience, v14-v110, 120+ matches). The bot raises 35-38% of flop/turn decisions but underbets, building small pots it cannot win.

## Root Cause (traced in source code)
In `strategy.py:choose_raise()`, the base ratios are correct:
- Flop: ratio = 0.60, Turn: ratio = 0.70, River: ratio = 0.85

But THREE stacking caps crush value-hand sizing:
1. **`induce_mode` cap** (line 239): `induce_cap = 0.29 + 0.05*round_idx + 0.05*wetness`. On a dry river (wetness~0): cap=0.44. On dry turn: cap=0.39. This fires for ALL nut hands via `value_bet_plan["induce"]=True` (postflop.py:479: `plan["induce"] = pot < 2600`).
2. **`thin_control` cap** (line 252): `thin_cap = 0.30 if round_idx <= 2 else 0.38`. Fires for ALL thin-tier hands via `value_bet_plan["thin_control"]=True`.
3. **`low_ratio` floor override** (line 254): when inducing, `low_ratio = 0.28`, further preventing any meaningful sizing.

Result: nut hands on dry river → ratio clamped to ~0.44 (not 0.85). Thin hands → clamped to 0.30-0.38. The base 0.70/0.85 is NEVER reached for value hands on static boards.

## The Fix (OFFENSIVE, structural)
Add a **value-tier sizing floor** in `choose_raise()` that applies AFTER all existing caps, ensuring strong/nut hands never underbet below a graduated floor. This is the explicitly PERMITTED direction: "offensive sizing floors/tiers remain permitted" (experience pool PARAMETER_TUNING).

### Implementation
In `choose_raise()`, after line 257 (`ratio = clamp(ratio, low_ratio, 1.45)`), add:

```python
# VALUE-TIER SIZING FLOOR: prevent induce/thin caps from crushing value bets.
# Offensive fix for avg_raise stuck at 0.4x pot. The induce_cap and thin_cap
# above correctly reduce POLARIZED/bluff sizing but incorrectly suppress VALUE
# extraction with strong/nut hands on static boards.
_value_tier = value_profile.get("tier", "none") if value_profile else "none"
if _value_tier in ("strong", "nut") and not semi_bluff and not blocker_bluff:
    if round_idx == 1:
        _value_floor = 0.50
    elif round_idx == 2:
        _value_floor = 0.58
    else:  # river
        _value_floor = 0.65
    # Only lift the floor if nutted_risk is LOW (we're not scared of a monster)
    if nutted_risk_score < 0.06:
        ratio = max(ratio, _value_floor)
```

This floor:
- Only applies to strong/nut VALUE hands (not semi-bluffs, not blocker bluffs)
- Only fires when nutted_risk is low (preserves existing risk-aversion on scary boards)
- Graduated by street (0.50 flop → 0.58 turn → 0.65 river) matching the theoretical value-extraction curve
- Does NOT touch defensive fold logic, call margins, or any exhausted direction

## SECOND OFFENSIVE ADDITION: Turn Check-Raise Polarized Range
Currently `_should_checkraise_trap()` only fires on the FLOP (round_idx != 1 → return False). The turn check-raise for strong/nut hands facing a turn bet is a distinct offensive decision point that extracts more value.

### Implementation
In `strategy.py`, modify `_should_checkraise_trap()` to ALSO fire on the turn (round_idx==2) with tighter conditions. Add this BEFORE `return False` at the round_idx check:

```python
# Turn check-raise: strong/nut hands on semi-dry turn vs aggressive opp
if round_idx == 2:
    if value_profile is None or value_profile.get("tier") not in ("strong", "nut"):
        return False
    if board_texture is None:
        return False
    if board_texture.get("dynamic", False):
        return False
    if board_texture.get("wetness", 0.0) > 0.35:
        return False
    confidence = opponent_model.get("confidence", 0.0)
    if confidence < 0.15:
        return False
    turn_aggr = opponent_model.get("postflop_aggr", 0.36)
    if turn_aggr < 0.35:
        return False
    seed = (sum(my_cards) * 7 + sum(public_cards) * 13) % 100
    if seed >= 30:  # 30% frequency (tighter than flop's 40%)
        return False
    return True
```
